# purrfect-deadline

Трекер дедлайнов, который не пугает паникой, а крадётся на мягких лапках 🐱

## О проекте

Учебный проект в рамках лабораторных работ по программной инженерии.
Цель — создать удобный и «нестрашный» трекер дедлайнов.

## Возможности

- добавление дедлайнов
- напоминания
- мягкая мотивация без паники;
- котики 🐾
